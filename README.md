# Practical Malware Analysis - Lab Solutions

Welcome to my malware analysis portfolio. I am Eitan Dahan, a Computer Science student at the Lev Academic Center, and this repository documents my hands-on progress through the labs in the book *Practical Malware Analysis*.

The primary goal of this project is to develop and demonstrate practical skills in reverse engineering and malicious software analysis within a safe, isolated environment. 

Throughout these lab write-ups, you will find applied techniques in:
* **Basic Static Analysis:** Identifying obfuscation (e.g., packed executables), analyzing PE headers, and extracting critical strings or Indicators of Compromise (IoCs).
* **Basic Dynamic Analysis:** Monitoring system interactions, network traffic, and registry modifications during malware execution.
* **Advanced Analysis:** (To be updated as I progress through the disassembly and debugging chapters).

Feel free to explore the lab folders for detailed, step-by-step methodologies and malware behavior analysis.
