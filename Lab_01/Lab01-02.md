### Question 3
<img width="787" height="60" alt="image" src="https://github.com/user-attachments/assets/cfa808f9-0e58-44f5-9d01-ccd8609d9b1d" />  

**Answer**
In order to see the imports lets open the file in Dependency walker.  
* <img width="800" height="600" alt="1" src="https://github.com/user-attachments/assets/25351fdd-cca2-4643-af87-a681da32a2f5" />
From the .DLL files we can see that the malware uses the internet in WININET.DLL and creates services with ADVAPI32.DLL.  
By looking at the imports of ADVAPI32.DLL we can see that the malware uses functions like "CreateServiceA", "OpenSCManagerA" and "StartServiceCtrlDispatcherA" which shows as that the file creates services that install itself in windows and even if you will restart the computer the virus will load automatically.  
By looking at WININET.DLL we can see that the malware uses functions like "InternetOpenA" and "InternetOpenUrlA" which shows that the malware uses the internet.    
By looking at KERNEL32.DLL we can see couple of things the first thing is the functions "CreateMutexA" and "OpenMutexA" which are creating a mutex that will make sure that the virus infected the computer only once so it will be harder do detect the virus.  
The second thing is from the functions "CreateWaitableTimerA" and "SetWaitableTimer" which are creating a timer for the malware to run in order to evade some antiviruses that the sandbox apply automatically when first running the malware.
