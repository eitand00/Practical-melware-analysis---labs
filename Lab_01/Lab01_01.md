**Code Insights by VirusTotal:**
* **Classification:** The sample is a file infector and system hijacker.
* **Typosquatting:** It copies a malicious payload (`Lab01-01.dll`) to `%WINDIR%\System32\kerne132.dll` (deliberately mimicking the legitimate `kernel32.dll`).
* **Execution & Spreading:** The malware recursively scans the `C:\` drive for executable files (`.exe`) and modifies their PE headers.
* **IAT Patching:** It patches the Import Address Table (IAT) to replace references to `kernel32.dll` with the malicious `kerne132.dll`, ensuring the payload is loaded whenever infected applications are executed.

There are couple of ways to check for packed or obfuscated files, I will go over the two of them.  
**PEiD -**  
At first we will check for the signature of the file, if the signature is known as a packed signature we can suspect that the file is packed.    

* <img width="800" height="600" alt="1" src="https://github.com/user-attachments/assets/9a33656a-1708-4612-a629-1301e8b46412" />
The signature not known as a packed signature so it is very likely that its not packed

**PEview -**  
We are moving to the more deep check to be sure that the file is indeed not packed.    
To make sure that the file is not packed we will check for big differences between Virtual size and raw data size in all the sections.    
For us to suspect the Virtual need to be bigger than raw size.    
The only section that can be like that and not raise suspicion is .data because its normal for the .data section in windows programs.
